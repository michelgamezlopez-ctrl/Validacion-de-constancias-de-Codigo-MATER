# Validación de constancias · Código Mater

Portal de verificación documental del **Curso-Taller Código Mater: Cuando Cada Minuto Cuenta**, Hospital IMSS-Bienestar de la Mujer de San Cristóbal de Las Casas.

## Seguridad del registro

El repositorio público **no almacena los nombres ni los tokens de las constancias reales**. El archivo `registro_hashes.json` conserva únicamente hashes SHA-256 y el estatus de cada constancia. La verificación se realiza localmente con los datos contenidos en el QR.

## Folios

Formato institucional: `HM-DES/CM-###/2026`.

## Estado actual

Existe únicamente un registro de prueba para verificar el funcionamiento técnico. Los registros reales se incorporarán cuando se cuente con la lista definitiva de participantes.

## Publicación

El repositorio incluye un flujo de GitHub Actions para publicar el portal con GitHub Pages.
